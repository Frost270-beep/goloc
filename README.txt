КАК ЗАПУСТИТЬ

1. Установите Node.js 20+.
2. Откройте терминал в этой папке.
3. Выполните:
   npm install
   npm start
4. Откройте http://localhost:3000

ДЛЯ ПУБЛИКАЦИИ В ИНТЕРНЕТЕ
Загрузите весь проект на хостинг, который поддерживает Node.js.
Команда запуска: npm start

ВАЖНО
- Общие результаты хранятся на сервере в data/votes.json.
- В текущей версии один голос разрешается с одного IP-адреса.
- Для серьёзного публичного голосования лучше использовать настоящую БД и авторизацию.
- Это не система анонимной проверки личности: IP-защита не гарантирует, что один человек не проголосует повторно из другой сети.
